# Friends of Nature (Друзья природы)

Образовательная платформа для детского сада и начальной школы: экологические игры, очки и «Лес», который растёт вместе с классом.

## Запуск

```bash
npm install
npm run dev
```

- Сайт: [http://localhost:5173](http://localhost:5173)
- Сервер комнат: [http://localhost:3001](http://localhost:3001)

Для урока с кодом комнаты нужны **оба** процесса (`npm run dev` запускает их вместе).

## Сценарии

### Учитель

1. Главная → **Я учитель**
2. Прочитать **Инструкцию к уроку**
3. Выбрать режим:
   - **Интерактивная доска** — одна игра на проекторе, класс подсказывает, учитель нажимает; очки в общий лес (+10 в панели комнаты)
   - **Телефоны учеников** — каждый ученик заходит по коду
4. Выбрать игры → **Открыть комнату** → показать **6-значный код**

### Ученик

1. Главная → **Я ученик** → код → имя → аватар → игры и личный «Лес»

### Без класса

**Играть без комнаты** на главной — очки сохраняются на этом устройстве.

## Игры

| Игра | Навык |
|------|--------|
| Сортировка мусора | Раздельный сбор |
| Чистая полянка | Уборка в природе |
| Посади дерево | Озеленение |
| Спаси речку | Причины загрязнения |
| Экономия энергии | Свет, вода, техника |
| Лови мусор | Мусор не в водоём |
| Эко-транспорт | Пешком, велосипед, автобус |
| Правила леса | Поведение на природе |
| Капля воды | Экономия воды |

```bash
npm run build
npm run preview
```

Сервер комнат при деплое нужно запускать отдельно и задать `VITE_SERVER_URL` для фронтенда.
